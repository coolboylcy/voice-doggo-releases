---

这个仓库只用来分发安装包，**不包含源代码**。

装完打开 App，权限没配齐时设置窗口会自己弹出来，点「一键授权」跟着走完即可。
往后有新版本，App 会自己提示更新。

## 遇到问题

- **按住右 Option 完全没反应**，而且权限都给了 —— 多半是终端开着「安全键盘输入」，
  它会让 macOS 停止向所有第三方程序派发按键。
  [完整机制和三种确认办法](https://voicedoggo.com/guides/secure-keyboard-entry/)
- **想在终端里给 Claude Code、Codex CLI 口述需求** ——
  [口述 prompt 的实际写法](https://voicedoggo.com/guides/cli-ai-voice-input/)
- **SSH 到远程机器、或在 tmux 里干活** ——
  [远程场景为什么是另一回事](https://voicedoggo.com/guides/ssh-tmux-voice-input/)
- 其余文章在[使用指南](https://voicedoggo.com/guides/)
